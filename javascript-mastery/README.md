# JavaScript Mastery

This repo now matches the structure style you shared.

Every topic folder has:

- `theory.md`
- `snippets.js`
- `interview-questions.md`
- `coding-output-practice.js`
- `coding-questions.md`
- `revision.md`

## How To Study One Topic

1. Read `theory.md`.
2. Run `snippets.js`.
3. Read `interview-questions.md`.
4. Run `coding-output-practice.js`.
5. Solve `coding-questions.md`.
6. Revise with `revision.md`.

## Start Here

```bash
npm run var
npm run let
npm run const
npm run hoisting
npm run scope
npm run tdz
```
