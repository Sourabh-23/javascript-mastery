# Promise Queue

Path: `2 ADVANCE JS\07_event-loop\06_promise-queue\01_theory.md`

## Simple Meaning

Promise future value represent karta hai: pending, fulfilled, rejected.

## Real Use

Use it async operations jaise API call, file read, timers me.

## Small Example

```js
Promise.resolve("done").then(console.log);
```

## Common Mistake

Promise result synchronously available nahi hota.

## Interview Answer

Promise Queue ka short interview answer: Promise future value represent karta hai: pending, fulfilled, rejected. Saath me ek small example aur common mistake bol doge toh answer strong lagega.
