# Abstraction

Path: `2 ADVANCE JS\09_oop\07_abstraction\01_theory.md`

## Simple Meaning

Abstraction internal complexity hide karke simple interface deta hai.

## Real Use

Use it complex logic ko simple method ke peeche rakhne ke liye.

## Small Example

```js
class Payment {
  pay() { return "payment done"; }
}
```

## Common Mistake

Abstraction ka matlab details delete karna nahi, hide karna hai.

## Interview Answer

Abstraction ka short interview answer: Abstraction internal complexity hide karke simple interface deta hai. Saath me ek small example aur common mistake bol doge toh answer strong lagega.
