# Polymorphism

Path: `2 ADVANCE JS\09_oop\08_polymorphism\01_theory.md`

## Simple Meaning

Polymorphism me same method name different objects/classes me different behavior de sakta hai.

## Real Use

Use it flexible code design me.

## Small Example

```js
class Dog { speak() { return "bark"; } }
class Cat { speak() { return "meow"; } }
```

## Common Mistake

Same interface ka meaning samjho, same implementation zaroori nahi.

## Interview Answer

Polymorphism ka short interview answer: Polymorphism me same method name different objects/classes me different behavior de sakta hai. Saath me ek small example aur common mistake bol doge toh answer strong lagega.
