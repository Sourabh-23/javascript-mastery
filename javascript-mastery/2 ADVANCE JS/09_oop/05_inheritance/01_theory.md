# Inheritance

Path: `2 ADVANCE JS\09_oop\05_inheritance\01_theory.md`

## Simple Meaning

Inheritance me child class parent class ke features use kar sakti hai.

## Real Use

Use it shared behavior avoid duplicate code ke liye.

## Small Example

```js
class Admin extends User {
  deleteUser() { return true; }
}
```

## Common Mistake

Over-inheritance code ko complex bana sakta hai.

## Interview Answer

Inheritance ka short interview answer: Inheritance me child class parent class ke features use kar sakti hai. Saath me ek small example aur common mistake bol doge toh answer strong lagega.
