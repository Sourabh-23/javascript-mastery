# Object This Coding Questions

Path: `13-this-keyword/object-this/coding-questions.md`

## Easy

1. Create one small example for Object This.
2. Print the output.
3. Change one input and run again.

## Medium

1. Use Object This inside a function.
2. Return a result instead of only printing.
3. Handle one edge case.

## Interview Discussion

- What is the input?
- What is the output?
- What can go wrong?
- What is the time complexity if this is a DSA problem?
