# Callback Hell

Path: `2 ADVANCE JS\06_async-javascript\02_callback-hell\01_theory.md`

## Simple Meaning

Callback function ko dusre function me argument ke form me pass karte hain.

## Real Use

Use it async flow, event handling, reusable logic me.

## Small Example

```js
function run(callback) {
  callback("done");
}
run(console.log);
```

## Common Mistake

Callback call karna bhoolna ya wrong time par call karna bug ban sakta hai.

## Interview Answer

Callback Hell ka short interview answer: Callback function ko dusre function me argument ke form me pass karte hain. Saath me ek small example aur common mistake bol doge toh answer strong lagega.
