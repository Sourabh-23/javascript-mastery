# Async Await

Path: `2 ADVANCE JS\06_async-javascript\05_async-await\01_theory.md`

## Simple Meaning

async-await Promise code ko readable synchronous style me likhne deta hai.

## Real Use

Use it API calls aur async flow ko clean banane ke liye.

## Small Example

```js
async function run() {
  const value = await Promise.resolve("done");
  return value;
}
```

## Common Mistake

await ke errors handle karne ke liye try-catch use karo.

## Interview Answer
