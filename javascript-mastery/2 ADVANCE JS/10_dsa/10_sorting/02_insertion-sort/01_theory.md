# Insertion Sort

Path: `2 ADVANCE JS\10_dsa\10_sorting\02_insertion-sort\01_theory.md`

## Simple Meaning

sort array order change karta hai.

## Real Use

Use it data ko ascending/descending order me lane ke liye.

## Small Example

```js
const nums = [10, 2, 5];
nums.sort((a, b) => a - b);
console.log(nums);
```

## Common Mistake

Numbers sort karte time compare function do.

## Interview Answer

Insertion Sort ka short interview answer: sort array order change karta hai. Saath me ek small example aur common mistake bol doge toh answer strong lagega.
