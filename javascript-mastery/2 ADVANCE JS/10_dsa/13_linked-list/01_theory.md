# Linked List

Path: `2 ADVANCE JS\10_dsa\13_linked-list\01_theory.md`

## Simple Meaning

Linked list nodes ka chain hota hai jahan each node next reference rakhta hai.

## Real Use

Use it pointer manipulation aur insertion/deletion understanding ke liye.

## Small Example

```js
const head = { value: 1, next: { value: 2, next: null } };
console.log(head.next.value);
```

## Common Mistake

Index direct access array jaisa fast nahi hota.

## Interview Answer

Linked List ka short interview answer: Linked list nodes ka chain hota hai jahan each node next reference rakhta hai. Saath me ek small example aur common mistake bol doge toh answer strong lagega.
