# Two Pointer

Path: `2 ADVANCE JS\10_dsa\08_two-pointer\01_theory.md`

## Simple Meaning

Two pointer technique me do indexes se data scan karte hain.

## Real Use

Use it sorted arrays, pair sum, palindrome, merge problems me.

## Small Example

```js
let left = 0;
let right = nums.length - 1;
while (left < right) {
  left++;
  right--;
}
```

## Common Mistake

Pointers move karne ka condition clear hona chahiye.
