# Dom Basics

Path: `2 ADVANCE JS\11_dom-browser-js\01_dom-basics\01_theory.md`

## Simple Meaning

DOM browser me HTML page ka object representation hai.

## Real Use

Use it elements select/update karne aur events handle karne ke liye.

## Small Example

```js
const button = document.querySelector("button");
button?.addEventListener("click", () => console.log("clicked"));
```

## Common Mistake

DOM code browser me run hota hai, Node.js me direct nahi.

## Interview Answer

Dom Basics ka short interview answer: DOM browser me HTML page ka object representation hai. Saath me ek small example aur common mistake bol doge toh answer strong lagega.
