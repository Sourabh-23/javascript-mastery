# Classes Coding Questions

Path: `18-oop/classes/coding-questions.md`

## Easy

1. Create one small example for Classes.
2. Print the output.
3. Change one input and run again.

## Medium

1. Use Classes inside a function.
2. Return a result instead of only printing.
3. Handle one edge case.

## Interview Discussion

- What is the input?
- What is the output?
- What can go wrong?
- What is the time complexity if this is a DSA problem?
