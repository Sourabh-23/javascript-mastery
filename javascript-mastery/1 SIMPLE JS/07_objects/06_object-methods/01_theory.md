# Object Methods

Path: `1 SIMPLE JS\07_objects\06_object-methods\01_theory.md`

## Simple Meaning

Object methods built-in helpers hain: keys, values, entries, assign.

## Real Use

Use it object ko loop/transform karne ke liye.

## Small Example

```js
const user = { name: "Amit", age: 25 };
console.log(Object.keys(user));
```

## Common Mistake

Object.keys values nahi deta, sirf keys deta hai.

## Interview Answer

Object Methods ka short interview answer: Object methods built-in helpers hain: keys, values, entries, assign. Saath me ek small example aur common mistake bol doge toh answer strong lagega.
