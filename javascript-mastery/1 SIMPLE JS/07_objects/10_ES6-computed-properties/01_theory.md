# ES6 Computed Properties

Path: `1 SIMPLE JS\07_objects\10_ES6-computed-properties\01_theory.md`

## Simple Meaning

Computed properties dynamic key names banane deti hain.

## Real Use

Use it jab key variable se aati ho.

## Small Example

```js
const key = "name";
const user = { [key]: "Amit" };
console.log(user.name);
```

## Common Mistake

Computed key ke liye square brackets zaroori hain.

## Interview Answer

ES6 Computed Properties ka short interview answer: Computed properties dynamic key names banane deti hain. Saath me ek small example aur common mistake bol doge toh answer strong lagega.
