# Higher Order Function Interview Questions

Path: `04-functions/higher-order-function/interview-questions.md`

## Beginner

1. What is Higher Order Function?
Answer: A higher-order function takes or returns a function.

2. Why do we use Higher Order Function?
Answer: To write predictable JavaScript and avoid runtime confusion.

3. Where is this used in backend code?
Answer: In handlers, services, helpers, validation, and data transformation.

## Intermediate

1. What is one common mistake with Higher Order Function?
Answer: Reading the code without tracing scope, value, or execution order.

2. How do you debug Higher Order Function issues?
Answer: Create a small snippet, log values step by step, and explain why each line runs.

## Advanced

1. Explain Higher Order Function in terms of memory and execution.
Answer: First identify what exists before execution, then trace runtime changes line by line.
