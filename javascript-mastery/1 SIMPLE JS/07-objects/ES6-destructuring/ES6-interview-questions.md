1. What is Destructuring?
Answer: Destructuring is a JavaScript topic. Learn the basic idea first, then run the snippet and practice questions.

2. Why do we use Destructuring?

3. Where is this used in backend code?

1. What is one common mistake with Destructuring?
Answer: Reading the code without tracing scope, value, or execution order.

2. How do you debug Destructuring issues?
Answer: Create a small snippet, log values step by step, and explain why each line runs.
