# Continue

Path: `1 SIMPLE JS\08_loops\08_continue\01_theory.md`

## Simple Meaning

continue current iteration skip karke next iteration par jata hai.

## Real Use

Use it unwanted values skip karne ke liye.

## Small Example

```js
for (let i = 1; i <= 5; i++) {
  if (i === 3) continue;
  console.log(i);
}
```

## Common Mistake

continue ke baad current iteration ka remaining code run nahi hota.

## Interview Answer

Continue ka short interview answer: continue current iteration skip karke next iteration par jata hai. Saath me ek small example aur common mistake bol doge toh answer strong lagega.
