# Break

Path: `1 SIMPLE JS\08_loops\07_break\01_theory.md`

## Simple Meaning

break loop ko immediately stop karta hai.

## Real Use

Use it jab answer mil gaya aur loop continue nahi karna.

## Small Example

```js
for (let i = 1; i <= 5; i++) {
  if (i === 3) break;
  console.log(i);
}
```

## Common Mistake

Nested loop me break sirf current loop stop karta hai.

## Interview Answer

Break ka short interview answer: break loop ko immediately stop karta hai. Saath me ek small example aur common mistake bol doge toh answer strong lagega.
