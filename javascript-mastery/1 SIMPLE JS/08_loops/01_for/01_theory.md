# For

Path: `1 SIMPLE JS\08_loops\01_for\01_theory.md`

## Simple Meaning

for loop fixed iterations ke liye best hai.

## Real Use

Use it index-based array/string traversal me.

## Small Example

```js
for (let i = 1; i <= 3; i++) {
  console.log(i);
}
```

## Common Mistake

Wrong increment/base condition infinite loop bana sakti hai.

## Interview Answer

For ka short interview answer: for loop fixed iterations ke liye best hai. Saath me ek small example aur common mistake bol doge toh answer strong lagega.
