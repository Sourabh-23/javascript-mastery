# ES6 For Of

Path: `1 SIMPLE JS\08_loops\05_ES6-for-of\01_theory.md`

## Simple Meaning

for-of iterable values par loop karta hai.

## Real Use

Use it arrays, strings, maps, sets ke values read karne ke liye.

## Small Example

```js
for (const ch of "JS") {
  console.log(ch);
}
```

## Common Mistake

Plain object directly for-of iterable nahi hota.

## Interview Answer

ES6 For Of ka short interview answer: for-of iterable values par loop karta hai. Saath me ek small example aur common mistake bol doge toh answer strong lagega.
