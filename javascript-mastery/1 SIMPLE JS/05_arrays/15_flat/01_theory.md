# Flat

Path: `1 SIMPLE JS\05_arrays\15_flat\01_theory.md`

## Simple Meaning

flat nested array ko given depth tak single array me convert karta hai.

## Real Use

Use it nested arrays normalize karne ke liye.

## Small Example

```js
const nums = [1, [2, [3]]];
console.log(nums.flat(2));
```

## Common Mistake

Default depth 1 hoti hai.

## Interview Answer
