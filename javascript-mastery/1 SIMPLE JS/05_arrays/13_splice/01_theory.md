# Splice

Path: `1 SIMPLE JS\05_arrays\13_splice\01_theory.md`

## Simple Meaning

splice original array ko mutate karke add/remove/replace karta hai.

## Real Use

Use it editable list operations me.

## Small Example

```js
const nums = [1, 2, 4];
nums.splice(2, 0, 3);
console.log(nums);
```

## Common Mistake

splice original array change karta hai.

## Interview Answer
