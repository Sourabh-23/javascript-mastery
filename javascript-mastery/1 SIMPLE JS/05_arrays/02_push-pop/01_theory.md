# Push Pop

Path: `1 SIMPLE JS\05_arrays\02_push-pop\01_theory.md`

## Simple Meaning

push end me add karta hai, pop end se remove karta hai.

## Real Use

Use it stack-like array operations me.

## Small Example

```js
const items = [1, 2];
items.push(3);
items.pop();
console.log(items);
```

## Common Mistake

Dono original array mutate karte hain.

## Interview Answer

Push Pop ka short interview answer: push end me add karta hai, pop end se remove karta hai. Saath me ek small example aur common mistake bol doge toh answer strong lagega.
