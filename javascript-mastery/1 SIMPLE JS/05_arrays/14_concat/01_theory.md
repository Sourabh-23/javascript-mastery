# Concat

Path: `1 SIMPLE JS\05_arrays\14_concat\01_theory.md`

## Simple Meaning

concat arrays/strings ko join karke new value return karta hai.

## Real Use

Use it non-mutating merge ke liye.

## Small Example

```js
const a = [1, 2];
const b = [3, 4];
console.log(a.concat(b));
```

## Common Mistake

concat shallow merge/copy karta hai.

## Interview Answer
