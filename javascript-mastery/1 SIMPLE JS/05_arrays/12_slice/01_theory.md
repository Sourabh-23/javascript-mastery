# Slice

Path: `1 SIMPLE JS\05_arrays\12_slice\01_theory.md`

## Simple Meaning

slice selected copy part return karta hai. Original change nahi hota.

## Real Use

Use it pagination, copy, substring-like array extraction me.

## Small Example

```js
const nums = [1, 2, 3, 4];
console.log(nums.slice(1, 3));
```

## Common Mistake

slice aur splice confuse mat karo.
