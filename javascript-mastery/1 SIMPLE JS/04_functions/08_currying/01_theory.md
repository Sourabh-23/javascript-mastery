# Currying

Path: `1 SIMPLE JS\04_functions\08_currying\01_theory.md`

## Simple Meaning

Currying function ko multiple small functions me todta hai, ek argument at a time.

## Real Use

Use it reusable configured functions banane ke liye.

## Small Example

```js
const add = (a) => (b) => a + b;
console.log(add(2)(3));
```

## Common Mistake

Currying aur partial application confuse mat karo.

## Interview Answer
