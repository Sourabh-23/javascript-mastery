# ES6 Arrow Function

Path: `1 SIMPLE JS\04_functions\03_ES6-arrow-function\01_theory.md`

## Simple Meaning

Arrow function shorter syntax hai. Iska apna this nahi hota.

## Real Use

Use it callbacks aur small functions me.

## Small Example

```js
const add = (a, b) => a + b;
console.log(add(2, 3));
```

## Common Mistake

Object method ke this ke liye arrow blindly use mat karo.
