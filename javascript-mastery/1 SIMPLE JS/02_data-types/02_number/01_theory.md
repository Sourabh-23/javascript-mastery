# Number

Path: `1 SIMPLE JS\02_data-types\02_number\01_theory.md`

## Simple Meaning

Number JavaScript ka numeric type hai. Integer aur decimal dono number hote hain.

## Real Use

Use it price, age, marks, count, calculation ke liye.

## Small Example

```js
const price = 99.5;
console.log(Math.round(price));
```

## Common Mistake

NaN bhi number type hi report hota hai, isliye Number.isNaN/Number.isFinite use karo.
