# ES6 Spread

Path: `1 SIMPLE JS\03_operators\09_ES6-spread\01_theory.md`

## Simple Meaning

Spread ... array/object ko expand karta hai.

## Real Use

Use it copy, merge, function arguments me.

## Small Example

```js
const nums = [1, 2];
const copy = [...nums, 3];
console.log(copy);
```

## Common Mistake

Spread shallow copy karta hai, deep copy nahi.

## Interview Answer

ES6 Spread ka short interview answer: Spread ... array/object ko expand karta hai. Saath me ek small example aur common mistake bol doge toh answer strong lagega.
