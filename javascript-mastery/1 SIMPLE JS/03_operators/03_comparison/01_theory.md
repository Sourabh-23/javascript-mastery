## Simple Meaning

comparison operators return booleans after comparing values, such as >, <, >=, and <=.

## Mental Model

When you read this topic, ask three things:

1. What value goes in?
2. What operation happens?
3. What value or side effect comes out?

## Real Use

You will use Comparison while reading output questions, writing small interview examples, and debugging real code. The main goal is not memorizing the name. The main goal is understanding exactly what JavaScript does line by line.

## Small Example

```js
const total = 100;
const isValid = total >= 50 && total <= 200;
console.log(isValid);
```
