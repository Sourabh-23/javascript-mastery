# Ternary

Path: `1 SIMPLE JS\03_operators\06_ternary\01_theory.md`

## Simple Meaning

Ternary short if-else expression hai jo value return karta hai.

## Real Use

Use it simple condition based value choose karne ke liye.

## Small Example

```js
const age = 20;
const type = age >= 18 ? "adult" : "minor";
console.log(type);
```

## Common Mistake

Complex nested ternary readability kharab karta hai.

## Interview Answer

Ternary ka short interview answer: Ternary short if-else expression hai jo value return karta hai. Saath me ek small example aur common mistake bol doge toh answer strong lagega.
