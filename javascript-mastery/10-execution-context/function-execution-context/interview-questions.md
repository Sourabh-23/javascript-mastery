# Function Execution Context Interview Questions

Path: `10-execution-context/function-execution-context/interview-questions.md`

## Beginner

1. What is Function Execution Context?
Answer: Function Execution Context is created for each function call.

2. Why do we use Function Execution Context?
Answer: To write predictable JavaScript and avoid runtime confusion.

3. Where is this used in backend code?
Answer: In handlers, services, helpers, validation, and data transformation.

## Intermediate

1. What is one common mistake with Function Execution Context?
Answer: Reading the code without tracing scope, value, or execution order.

2. How do you debug Function Execution Context issues?
Answer: Create a small snippet, log values step by step, and explain why each line runs.

## Advanced

1. Explain Function Execution Context in terms of memory and execution.
Answer: First identify what exists before execution, then trace runtime changes line by line.
