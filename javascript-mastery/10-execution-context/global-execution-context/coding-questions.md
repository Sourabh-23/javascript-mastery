# Global Execution Context Coding Questions

Path: `10-execution-context/global-execution-context/coding-questions.md`

## Easy

1. Create one small example for Global Execution Context.
2. Print the output.
3. Change one input and run again.

## Medium

1. Use Global Execution Context inside a function.
2. Return a result instead of only printing.
3. Handle one edge case.

## Interview Discussion

- What is the input?
- What is the output?
- What can go wrong?
- What is the time complexity if this is a DSA problem?
